Your game save
Fills in your levels, toolbelt gear, shop upgrades, distractions, guild ranks, pets and Mastery Guild progress from your save_….sav file (in the game’s saves folder). Read-only — the file never leaves your computer. Chrome and Edge won’t let a web page watch files inside AppData, so to auto-update, have Windows keep a copy in Documents and watch that copy.
How to keep a copy in DocumentsOpen PowerShell, run this and leave the window open while you play (replace the first path with your saves folder). It re-copies the save every minute when the game saves:
robocopy "C:\Users\YOU\AppData\Roaming\…\saves" "$env:USERPROFILE\Documents\MV2 Save" save_*.sav /MOT:1
Then click Watch my save and pick the copy in Documents\MV2 Save.
